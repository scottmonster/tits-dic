# Local benchmark data

This directory contains benchmark processing scripts. Audio, reference
transcripts, downloaded datasets, and generated benchmark results are excluded
from the public repository and remain local.

The research tools in `scripts/` and this directory's `scripts/` subdirectory
expect your own inputs. The dashboard under `tst/` reads results from
`tst/data/extracted_data/`; generate those results locally before using it.
The dictation installer and unit tests do not require these datasets.
